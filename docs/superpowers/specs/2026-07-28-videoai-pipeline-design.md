# VideoAI — автоматический pipeline детских обзоров игрушек

Дата: 2026-07-28. Статус: дизайн утверждён в брейншторме, ждёт вычитки перед планом реализации.

## 1. Цель

Локальное приложение на macOS (Apple Silicon): в папку кладутся несколько клипов-дублей
(ребёнок делает обзор игрушки, речь на английском) + опциональный бриф. Pipeline
автоматически: транскрибирует, находит лучшие дубли, вырезает паузы и сбои, собирает
смысловой монтаж с B-roll и графикой, показывает черновик на локальной ревью-странице,
после Approve рендерит финальное видео 16:9, шорты 9:16, обложку и метаданные для YouTube.

**Без автозагрузки на YouTube** — готовые файлы складываются в `output/`, публикация вручную.

Типовой проект: 15–20 минут исходников → финал ~3–5 минут + 2–3 шорта.

## 2. Философия

1. **Стадия = атом.** Каждая стадия читает артефакты из `work/`, пишет артефакты в `work/`.
   Общего состояния нет — только файлы (JSON + медиа). Любая стадия запускается отдельно
   (`videoai run <проект> --stage analyze`), её вход/выход можно посмотреть глазами и
   переписать её внутренности, не трогая остальное.
2. **Провайдер = плагин стадии.** Стадия объявляет интерфейс, реализации сменные:
   бесплатные (локальные/подписочные) и платные (API). Выбор — строчка в `config.yaml`.
3. **Кэш по содержимому.** Артефакт пересчитывается только если изменился вход или провайдер.
   Платные вызовы никогда не повторяются зря. Режим `--dry-run` с мок-ответами для разработки.
4. **v1 полностью бесплатная** (Claude Max + Codex/OpenAI подписка + локальные инструменты).
   Платные API подключаются потом по одному, с A/B-сравнением артефактов (`work/runs/`).
5. **Карта апгрейдов живёт в репо** (`docs/state/`): что включено сейчас, что можно улучшить,
   сколько стоит, как включить.

├── templates/               # Remotion-проект: библиотека графики, karaoke-субтитры
├── review/                  # локальная ревью-страница (FastAPI)
├── assets/                  # музыка (YouTube Audio Library), лого, шрифты

## 4. Стадии и провайдеры

| # | Стадия | Free v1 | Платный апгрейд (цена/видео) |
|---|--------|---------|------------------------------|
| s01 | Ingest: ffprobe, нормализация звука (loudnorm −14 LUFS), прокси 720p | ffmpeg | — |
| s02 | Quality Gate: смаз/трясучка/пересвет/клиппинг/чёрные кадры → JSON-оценки | OpenCV + ffmpeg | — |
| s02b | Механический rough cut: вырезание мёртвого воздуха ДО LLM | auto-editor (subprocess) | — |

| s05 | StoryPlan → Timeline: сюжет, выбор дублей, точки резки, тексты | Claude Agent SDK (Max) | — |
| s06 | B-roll: стоки, AI-анимации (Claude→Remotion, alpha), нарезка brand/, [AI-видео] | Pexels/Pixabay + генеративная моушн-графика $0 | Kling/Hailuo ~$0.3/клип; Veo 3.1 ~$1–3/клип; полуручной путь — Flow-кредиты подписки Google AI Pro |

| s08 | Рендер 16:9: нарезка → Remotion-слои (субтитры, графика, панч-зумы, дакинг) | ffmpeg (через auto-editor v3) + Remotion | — |
| s08b | AI-ревьюер: модель смотрит черновик, чинит ляпы до показа человеку | Claude по кадрам черновика | Gemini смотрит видео (~$0.2) |
| s09 | Шорты: выбор моментов, face-tracking 9:16, karaoke-субтитры | openshorts reframe + MediaPipe + Remotion | — |

## 5. Артефакты (контракты между стадиями)

Все JSON валидируются Pydantic-схемами на входе и выходе стадий.

### input/project.yaml (единственный ручной файл; всё опционально кроме title)
```yaml
title: "Обзор Hot Wheels Monster Truck"
toy_name: "Hot Wheels Monster Trucks Mega Wrex"
language: en
target_duration_seconds: 240
shorts: { count: 3, duration_seconds: 45 }
must_include: ["момент распаковки", "прыжок с трамплина"]
avoid: ["кадры, где виден адрес на коробке"]
style: playful            # playful | calm | epic
notes: |
  Свободные заметки.
```

### work/03-transcript.json
Пословные таймкоды + confidence (подсветка сомнительных слов на ревью) + speech_spans
от silero-vad. Verbatim: запинки и «эм-м» сохраняются — они нужны для резки.
Дополнительно — «упакованный» вид по фразам (паттерн video-use, ~1/10 токенов) для LLM.

### work/04-analysis.json
Единый формат независимо от провайдера: сегменты с `content`, `delivery_score`,
`visual_score`, `emotion`, `is_failed_take`, `take_group`, `shorts_candidate`, `quality`.
`take_group` — ключ к выбору лучшего дубля из повторов между клипами.

**Детекция дублей** — двухступенчатая: детерминированный кандидат-детектор
(повтор начального n-грамма фразы с нечётким совпадением + длинная пауза + оборванное
предложение — из данных parakeet+silero), LLM только судит, какой дубль лучше.

### work/05-storyplan.json → work/05-timeline.json
StoryPlan — человекочитаемый («что рассказываем»): секции Hook/…, выбор клипов,
название/описание/теги. Timeline — машинный центральный контракт. Схема — гибрид:
- геометрия auto-editor v3: целочисленный timebase, клипы `{src, start, dur, offset}`,
  слои `v[]/a[]` — арифметическая валидация стыков;
- поля происхождения video-use: `quote`, `reason`, `beat` на каждом сегменте;
  валидатор заново привязывает quote к транскрипту — ловит галлюцинации таймкодов;
- дорожки graphics (компонент+props из шаблонной библиотеки) и captions;
- конвертеры: → auto-editor .v3 (рендер + экспорт Resolve/Premiere/FCP), → OTIO.

**Железные правила валидатора** (по video-use): не резать внутри слова; отступ 30–200 мс
на краях реза; тишина ≥400 мс — безопасная точка, <150 мс — нет; afade 30 мс на границах;
клипы в пределах длительности файлов; графика — только существующие компоненты;
субтитры в safe zone.

### work/06-review-decisions.json
Правки человека с ревью-страницы (отдельно от timeline — полная воспроизводимость).

## 6. B-roll: пять источников

1. **Стоки** (Pexels/Pixabay API, $0) — атмосфера; логика подбора — по образцу MoneyPrinterTurbo.
2. **Генеративная моушн-графика** ($0): gpt-image/бесплатная картинка → Claude пишет
   Remotion-компонент → headless-рендер .mov с альфой → оверлей или вставка. Удачные
   сценки копятся в `animations-library/` и переиспользуются. Валидация — цикл
   generate→run→error-feedback→regenerate (паттерн generative-manim).
3. **Официальные промо бренда** из `input/brand/` — вставки <10 сек с комментарием поверх
   (митигация Content ID).
4. **AI-видео из фото игрушки** (платный апгрейд): Kling/Hailuo/Veo через fal.ai-шлюз.
   **Ребёнок никогда не попадает в генераторы** — только игрушка (политики + безопасность).
5. **Ручные закладки**: всё, что человек положил в `input/broll/`, подхватывается.

Графика: **библиотека шаблонов с props** (LLM не пишет свежий React для стандартных
элементов — стиль канала не плывёт). База — Remocn-компоненты (MIT, копируются в репо)
+ карточки-рецепты video-shotcraft (Apache) + наш детский стиль поверх.

## 7. Ревью-страница (FastAPI, локально)

Один экран: плеер черновика (прокси 720p, склейка stream-copy — пересборка за секунды);
storyboard-карточки сцен с ✓/✗, кнопкой «Alt» (другие дубли из take_group с оценками)
и «↻» (заменить B-roll); субтитры с подсветкой низкого confidence и инлайн-правкой;
выбор обложки из 6 кандидатов; редактируемые название/описание; [Пересобрать] [Approve].

После Approve: финальный рендер → шорты (отдельный ряд карточек, можно выключать/
перегенерировать) → упаковка.

## 8. Рендер

**16:9, два прохода:** (1) auto-editor/ffmpeg собирает базовую дорожку по Timeline
(резы по пословным таймкодам, аудио-цепочка); (2) Remotion-композиция накладывает
karaoke-субтитры (@remotion/captions, template-tiktok паттерн), графику из шаблонов,
AI-сценки с альфой, панч-зумы 1.0→1.15 на высоком delivery_score, музыку с дакингом
−12 дБ под speech_spans.

**Шорты 9:16:** моменты из shorts_candidate (хук в первые 2 сек) → кадрирование по
алгоритму openshorts («тяжёлый штатив»: безопасная зона 25%, jump-confirmation;
рендер ffmpeg sendcmd, звук stream-copy; hwaccel videotoolbox) → при необходимости
ByteTrack-идентификация ребёнка (verthor, MIT) → Remotion 1080×1920, субтитры в
верхней трети. Наше ноу-хау: приоритет ребёнка при выборе субъекта и расширение
кадра вниз при демонстрации игрушки.

**Обложка:** кандидаты по резкости (Laplacian) + улыбке (MediaPipe) → выбор на ревью →
renderStill() в стиле канала.

## 10. Комплаенс и риски

- **COPPA/Made for Kids**: контент почти наверняка «Made for Kids» → без комментариев и
  персонализированной рекламы; metadata.md содержит чек-лист с обязательными галочками
  Made for Kids ✓ и «содержит AI-контент» ✓. Декларировать честно (FTC сканирует, штрафы
  до ~$51k/нарушение).
- **Content ID**: брендовые промо — <10 сек с комментарием, или запрашивать разрешение
  бренда. Музыка — только библиотеки с чистыми правами.
- **Дети и генераторы видео**: фото/кадры ребёнка никогда не отправляются в видеогенераторы.
- **Приватность**: на бесплатных LLM-уровнях данные могут идти в обучение — домашние видео
  только через платный API-уровень Gemini или локально/подписочно (Claude Max, Codex).
- **Волатильность вендоров** (Sora умерла за полгода; биллинг Agent SDK менялся дважды):
  вся платная периферия — за интерфейсами провайдеров; генерация видео — через fal.ai-шлюз.
- **Качество free-анализа**: транскрипт+кадры не слышат подачу; ревью-страница —
  обязательный корректирующий контур; первый платный апгрейд — Gemini-анализ.

## 11. Ошибки, QA, тестирование

- Стадия падает — pipeline останавливается с понятной ошибкой и подсказкой перезапуска
  этой стадии; артефакты предыдущих стадий целы (атомарность).
- QA до рендера: валидатор Timeline (§5). QA после: файл открывается, длительность/fps/
  громкость в норме, нет чёрных кадров и тишины, субтитры в кадре.
- AI-ревьюер (s08b): оценки связности/темпа с порогом, ≤2 итераций автопочинки.
- Тесты: unit на схемы/валидатор/кэш; golden-файлы артефактов на фикстурном мини-проекте
  (3 коротких клипа); e2e прогон в --dry-run на CI без платных вызовов.

## 12. Вне скоупа v1

- Автозагрузка на YouTube (YouTube Data API, OAuth, аудит) — осознанно исключена.
- Дубляж/перевод, несколько детей в кадре (диаризация), поиск по архиву съёмок
  (медиа-индекс SQLite) — кандидаты в v2+.
